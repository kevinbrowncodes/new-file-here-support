# New File Here

New File Here adds **New Text Document** to Finder's right-click menu on the Mac, the way
Windows does, including when you right-click empty space in a folder. No account, no network,
no data collection.

## Getting started

1. Open **New File Here**. Its setup window opens.
2. Step 1 shows whether the Finder extension is on. If it isn't, click **Turn On in System
   Settings…** and switch on **New File Here** under General › Login Items & Extensions.
3. Click **Grant Access to Home Folder…**, then **Grant Access**. That covers Desktop,
   Documents, Downloads and everything else in your home folder.
4. In Finder, right-click empty space in any folder and choose **New Text Document**. The new
   file is selected: press Return to name it.

## What else it does

- **New Document ▸** in the same menu makes Markdown, Rich Text, HTML, JSON and CSV files.
- Right-click a **folder** and the document goes inside it; right-click a **file** and it goes
  next to it.
- If the name is taken it counts up: New Text Document (2), (3) and so on. It never
  overwrites anything.
- The **menu bar icon** makes documents in the last folder you opened in Finder, a recent
  folder, or on the Desktop. Turn on **Open at Login** to keep it there after a restart.

## Frequently asked questions

**New Text Document isn't in the menu.** Open New File Here and check step 1. If it says On
and the item is still missing, turn the extension off and on again in System Settings ›
General › Login Items & Extensions.

**I chose it, but no file appeared, and the setup window opened.** The folder is outside the
folders you granted (an external drive, say). Grant that folder or drive in the setup window
and the document is made at once.

**Why does it need access to my home folder?** macOS keeps apps from writing to your folders
unless you choose them. New File Here only ever creates the documents you ask for, in the
folder you right-clicked.
