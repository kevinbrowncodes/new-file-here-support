# New File Here support site

Static content for the PUBLIC repo `kevinbrowncodes/new-file-here-support` (GitHub Pages).
`scripts/publish-support.sh` copies this folder there verbatim; this folder is the source of
truth, and `gates/support-published.sh` fails a push when the published copy differs.

- `index.md`: support page (App Store "Support URL")
- `privacy.md`: privacy policy (App Store "Privacy Policy URL")
